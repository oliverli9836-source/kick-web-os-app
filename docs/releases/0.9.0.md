Stream for Kick for LG webOS, now with a **danmaku chat overlay** ported from [uKick](https://github.com/berkaygediz/uKick):

- Public chat from live streams scrolls across the top of the video, with Kick emotes shown as images and links removed.
- Messages use non-overlapping lanes and a bounded queue, so busy chats stay readable and the TV stays responsive.
- **Chat overlay: On / Off** in the player controls (live streams only); the choice is remembered. On by default.
- Written for the TV's older browser engine (CSS transitions instead of Web Animations; works on webOS 3's Chromium 38).
- The TV service fetches Kick's current chat socket credentials per channel, falling back to the last known key.

Replays have no live chat, so the overlay appears only on live streams. This build was checked with the project's test suite and against live Kick chat in a desktop browser; it has not yet been verified on a TV.

Install `com.jakubjirak_0.9.0_all.ipk` with webOS Dev Manager or your Homebrew setup. The app and service IDs are unchanged, so installing over 0.8.x keeps your favorites and history. Keep the previous IPK for rollback. Verify the download against SHA256SUMS.
